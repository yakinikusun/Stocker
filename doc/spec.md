# 冷蔵庫・在庫管理システム「Freezer」仕様書

## 1. システム概要

本システムは、個人および特定家庭・小規模グループにおける冷蔵庫・冷凍庫・野菜室・パントリー等の在庫管理を簡略化・効率化するためのクラウド型在庫管理Webアプリケーション（PWA）です。

- **アプリ名**: Freezer（フリーザー）
- **対象ユーザー**: 完全招待制・家庭内複数ユーザー（管理者 / 一般ユーザー）
- **主要アクセス機器**: スマホ（iOS / Android）および PC・タブレットブラウザ
- **設計方針**: セキュリティ（データ改ざん防止・漏洩防止）を最優先しつつ、日常の運用の手間を最小化する。

---

## 2. アーキテクチャ ＆ 技術スタック

本システムは独自バックエンドサーバーを保持せず、フロントエンドから直接マネージドサービス（Supabase）を呼び出すサーバーレス構成を採用しています。

```
[スマホ / PC ブラウザ / PWA]
        ↓ HTTPS (Cloudflare Pages ホスティング想定)
[Vite + React 19 + TypeScript (SPA)]
        ↓ @supabase/supabase-js SDK / LocalStorage Fallback
[Supabase Backend]
  ├─ PostgreSQL（在庫・履歴・保管場所・プリセット・タグ・ユーザーデータ）
  ├─ Auth（セッション管理）
  └─ Row Level Security（アクセス制御 ＆ 改ざん防止）
```

### 技術スタック
| カテゴリ | 採用技術 | 備考 |
|---|---|---|
| フロントエンド | React 19 + TypeScript + Vite | SPA構成 |
| Styling | Tailwind CSS v4 | 白・グレーベースのシンプルUI |
| アイコン | Lucide React | |
| バーコード読み取り | `@zxing/browser` / `@zxing/library` | Webカメラバーコードデコード |
| PWA対応 | `vite-plugin-pwa` | ホーム画面追加・オフラインキャッシュ |
| DB / API / Auth | Supabase (PostgreSQL / RLS) | デュアルモード (未設定時はLocalStorageデモ動作) |

## 4. 判定ロジック仕様

### 在庫量の判定仕様
在庫状態の判定は以下の **二値判定（バイナリ）** に統一されています。

1. **在庫あり (`in_stock`)**: `current_stock > 0`
   - 緑色のステータスバッジ「在庫あり (個数)」を表示。
2. **在庫切れ (`out_of_stock`)**: `current_stock === 0`
   - 赤色の点滅バッジ「在庫なし」を表示。

## 5. 画面構成および機能仕様

本アプリケーションは以下の4つの主要画面で構成されます。

### 5.1 メイン画面 (在庫一覧)
- **保管場所フィルター**: タップで指定の保管場所（例: `冷蔵庫`、`冷凍庫`、`野菜室`）の在庫のみを抽出。
- **マルチ条件検索**: 商品名・JANコード・保管場所名・タグ名でのリアルタイム検索。
- **ステータス・タグ絞り込み**: 在庫あり / 在庫切れの二値フィルターおよびタグフィルター。
- **表示切り替え**: カード表示（グリッド）とリスト表示（テーブル）の切り替え。
- **クイック操作**: 各商品カードから直接「+1 (追加)」「-1 (消費)」操作。
- **詳細数量・理由変更モーダル**: 変更理由（入荷、消費・調理使用、廃棄、棚卸修正）を選択して更新。

### 5.2 在庫設定画面 (マスタ管理)
- **保管場所一覧**: 保管場所の追加・一覧確認・削除。
- **在庫プリセット一覧**: 在庫が切れた商品の再呼び出し用プリセットの登録・一覧・削除。「在庫に追加」ボタンでワンタップで指定保管場所へ在庫補充可能。
- **タグ一覧**: 分類用タグの追加・一覧確認・削除。

### 5.3 操作履歴画面 (監査ログ)
- 誰が・いつ・どの保管場所で・どの商品をどれだけ変更したかの全履歴ログを表示。
- 日時・商品名・変動数（+緑 / -赤）・理由タグ・担当ユーザー名を表示。
- 履歴に対する検索・絞り込み機能。

### 5.4 アカウント設定画面
- ユーザー情報の確認・編集。
- ユーザー権限（`管理者` vs `一般ユーザー`）の切り替え。
  - ※管理者 (`admin`): 商品マスタの最終削除権限を保持。
  - ※一般ユーザー (`member`): 在庫数量変更・追加・閲覧が可能。
- Supabase接続設定 (URL / Anon Key) の保存および動作モード確認。
- ローカルデモデータの初期化リセット機能。
- ログアウト。

## 6. レスポンシブ UI / UX 設計

- **PC表示 (画面幅 768px 以上)**:
  - ヘッダー左側にロゴ、右側に主要画面切り替えタブを表示。
- **スマホ表示 (画面幅 768px 未満)**:
  - ヘッダーはロゴのみのコンパクト表示。
  - 画面下部に固定ボトムナビゲーションバー（`メイン`、`在庫設定`、`操作履歴`、`アカウント`）を表示。
- **デザインテーマ**: 白とグレーを基調とした、清潔感と視認性の高いミニマルUIデザイン。
