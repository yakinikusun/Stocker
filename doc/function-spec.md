# 冷蔵庫管理システムについて

## 目的
冷蔵庫・冷凍庫・野菜室、またその他の保管場所の在庫の管理を簡略化するためのサービスです

### 対象
完全招待制により特定家族にのみ使用ができます<br>
主にスマホ・タブレットを用いて接続されることが想定されています

#### アカウントの種類
- 管理者
- 一般ユーザー

## 主な機能
- 保管場所ごとの在庫の確認・追加・削除
- 既存の保管場所である『冷蔵庫・冷凍庫・野菜室』からの保管場所の追加・削除
- バーコードを用いた在庫の登録
- 在庫のタグ付け
- 在庫の検索機能
  - 保管場所ごと
  - 名前
  - タグごと
- 在庫のプリセット(ストックが尽きた後の再呼び出し用)

## 画面一覧 
- ログイン
- 登録画面
- メイン画面(ログアウト時にはLP)
- 在庫設定への移動用画面(そこから以下に移動)
  - 保管場所一覧
  - 在庫プリセット一覧
  - タグ一覧
- アカウント設定

### メイン画面
- 主に在庫一覧が表示されており、在庫の追加・消去が行えます
- 簡易的なフィルタ機能により保管場所ごとに見れます
- 検索機能により名前・タグ・保管場所で絞れます

### アカウント設定
- アカウントの情報の編集
- ログアウト

### 保管場所・在庫プリセット・タグ一覧
確認・追加・編集・削除を行えます

## 主要コンポーネント
- ヘッダー・フッダー
- 在庫登録
- 在庫編集

### ヘッダー・フッダー
- ヘッダーはロゴのみ
- フッダーにはメイン画面・在庫設定への移動用画面・アカウント設定への移動を

### 在庫登録
- 写真・名前・個数の指定
- プリセットへの登録
- 呼び出し機能
 - バーコードからの呼び出し
 - プリセットからの呼び出し

### 在庫編集
- 写真・名前・個数の変更
- 削除(個数を0にする)

## UIのイメージ
- 白と灰色をベースとした簡素なデザイン
- アニメーションは最小限に
